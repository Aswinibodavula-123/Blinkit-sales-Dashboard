# Blinkit-sales-Dashboard
Interactive Power BI dashboard analysing 1.2M+ Blinkit grocery sales records - helping identify top performing outlets, high- demand product categories, location- base sales trends to support smarter inventory and expansion decisions.
🟡 Blinkit Sales Performance Dashboard — Power BI
Transforming 1.2M+ grocery sales records into actionable retail intelligence
1. Project Title / Headline
   
🛒 Blinkit Retail Analytics: Sales & Outlet Performance Dashboard
A dynamic, interactive Power BI dashboard built to analyze Blinkit's grocery sales data — uncovering outlet performance patterns, product demand trends, and location-based revenue insights to support smarter business decisions.

3. Short Description / Purpose
This dashboard empowers retail analysts, business strategists, and operations teams to explore Blinkit's sales data across multiple dimensions — outlet size, location tier, item type, and fat content. It transforms raw transactional data into clear visual insights, enabling faster and more confident decision-making around inventory planning, outlet expansion, and product prioritization.
Built as part of a self-driven data analytics learning journey — May 2026.

5. Tech Stack
The dashboard was built using the following tools and technologies:
📊 Power BI Desktop — Main data visualization platform used for report creation and interactive design

🔄 Power Query — Data transformation and cleaning layer for reshaping and preparing raw sales data

🧮 DAX (Data Analysis Expressions) — Used for calculated measures, KPI cards, dynamic visuals, and conditional logic

🗂️ Data Modeling — Relationships established among tables to enable cross-filtering and aggregation across visuals

📁 File Format — .pbix for development and .png for dashboard preview screenshots


7. Data Source
Source: Blinkit Grocery Sales Dataset (publicly available sample dataset)
The dataset contains 1,201,681+ sales records across Blinkit outlets in India, including:
Outlet details — type, size, location tier, establishment year
Product details — item type, fat content, visibility, MRP
Sales metrics — total sales, average rating, number of items sold
Coverage: Tier 1, Tier 2, Tier 3 cities across India
Time range: 2010 – 2022 (outlet establishment years)
8. Features / Highlights

   
🔴 Business Problem
Blinkit operates hundreds of outlets across India with vastly different performance levels. Without a centralized view, it is difficult for business teams to identify which outlet types, locations, or product categories are underperforming — leading to poor inventory decisions and missed expansion opportunities.

🎯 Goal of the Dashboard

To build a single-page interactive report that allows stakeholders to:
Instantly see overall sales health via KPI cards
Compare performance across outlet sizes, types, and location tiers
Identify high-demand product categories
Filter and drill down by outlet location, size, and item type

💡 Business Impact & Insights

Tier 3 cities outperform Tier 1 — suggesting untapped suburban/rural demand that Blinkit could prioritize for expansion
Supermarket Type 1 outlets generate 7.87M in sales — nearly 6x more than Grocery Stores, highlighting format superiority
Fruits, Snacks, and Household items are the top 3 categories — useful for shelf space and procurement planning
2018 saw the highest outlet establishment growth correlating with a sales peak — validating aggressive expansion strategy
Average rating of 3.92 across all outlet types shows consistent customer satisfaction, with room to improve Tier 1 performance

11. How to Use
Download the .pbix file from this repository
Open it in Power BI Desktop (free download from Microsoft)
Use the left-side Filter Panel to slice by:
Outlet Location Type (Tier 1 / Tier 2 / Tier 3)
Outlet Size (Small / Medium / High)
Item Type (Fruits, Dairy, Snacks, etc.)
All visuals update dynamically based on your filter selection
